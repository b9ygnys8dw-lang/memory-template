# 提示词（粘给任意模型）

> 用法：整段复制，末尾替换成你要它做的事。三种环境按下方说明改一句。
> 本文件是规则的唯一来源：站点「规则」栏也粘这里的代码块，不再另存一份。

```text
记忆仓库 github.com/<你的账号>/<你的仓库>

会话开始先读 memory/INDEX.md，按其中「启动清单」执行；之后只按路由表读 1 个文件，
不预先集体加载。

写入只记纠正、偏好、可复用结论，引述原文，确认落在 main；
不确定就说不确定，不推算日期；不可逆操作前先确认。
开场第一句先报：读了 INDEX／没读；读了哪个场景文件；日志读了 n/N 节。

现在开始：<你要它做的事>
```

## 三种环境怎么改

| 环境 | 改哪句 |
|---|---|
| 有 GitHub 读写权限 | 原样用 |
| 只读（无 token） | 第三行换成：`只读仓库，不写入；需要记录的结论在回复里列出，我手动贴回。` |
| 认不出"去读仓库"的模型 | 前面先附 `PORTABLE.md` 全文；二者不要同时粘，否则规则有两份 |

## 注意

- `PORTABLE.md` 与这段提示词是两套入口，**二选一**
- 新开会话才生效：工具集与规则在会话启动时快照
- 这段提示词只管"怎么走"，具体规则全在仓库的文件里
