# 记忆系统

适用：读写长期记忆、按事件检索、标注作废。

## 入口

每次会话：读 `memory/INDEX.md` + `memory/profile/ai.md`，再按 INDEX 路由读 **1 个**场景文件，整读（每个 ≤3KB）。

- 不确定读哪个：用关键词 grep 全部 `触发:`，或 grep `LOG.md` 标题
- 读不到就直说，不凭印象补全
- 没有预先加载，一律按需读

## 写入

| 内容 | 写到哪 |
|---|---|
| 语气、边界 | `profile/ai.md` |
| 我的行为记录（哪次被接受／否决） | `profile/behavior.md` |
| 身份、目标、交付偏好 | `profile/user.md` |
| 交付规范 | `knowledge/delivery.md` |
| 设计与方案 | `knowledge/design.md` |
| 平台、时间、MCP 路径 | `knowledge/platform.md` |
| 文件间关系（谁依赖谁） | `knowledge/relations.md`（唯一来源） |
| 情景 | `LOG.md` |

- 只记纠正、偏好、可复用结论；普通问答不写
- 结论写仓库；未验证的写 MCP 草稿并标"未定稿"
- 写入走 git 工作副本：clone 到 `/workspace/memory-repo`，改 → `wc -c` 校验非空 → commit → `pull --rebase` → push
- 提交后确认在 `main`；非 main 说"仅在分支，未入主分支"
- 写完引述原文，不报数量

## 条目格式

画像条目一行：`- YYYY-MM-DD 一句话`，保留原话，可选 `触发:`。

日记怎么写、写不写、情绪怎么判断 → **只读 `knowledge/writing.md`**，本技能不重复规则。

## 好留坏扔

- 好的留下，坏的标 `作废 YYYY-MM-DD`；**不物理删除**，原文保留
- "坏"由用户判定，我只提议，不自行裁决
- 同一主题多条 → 以日期最新的为准，旧的自动失效

## 检索（两段式）

- 粗取：`grep "^## " LOG.md | grep -v 作废`，标题自带结论
- 重排：按语义挑 1–2 条最相关的标题
- 细读：只读挑中的那节，不整读全文
- 命中即记：该条真的影响了判断，就在 `HITS.md` 追加一行 `YYYY-MM-DD 条目名`
- 三层优先级：仓库（命中即停）→ MCP 草稿（标"未定稿"）→ 说"没有记录"
- 不两边并读拼接，不把草稿当定稿；冲突以仓库为准

## MCP

- 只做草稿；写完同会话 grep 一次，能命中才算写完
- 图谱库实体名用仓库原名，摘要库一律 `S:` 前缀，两库不共享实体
- json 不存在就忽略；需要关联查询时才按 `knowledge/mcp-seed.md` 建
- 数据文件路径见 `knowledge/platform.md`

## 时间

只查两次：会话开始一次、每次写记忆文件前一次（与写入合并，不单独等）。日期按 UTC。

## 不做什么

- 不压缩、不降档、不归档、不算权重
- 不删条目，包括"看起来没用"的
- 不推算日期，不批量通读 `LOG.md`
- 结论不写进 MCP，草稿不当作事实

## 失败处理

- 读不到文件 → 直说，不补全
- 写入失败或只在分支 → 直说，不说"已记住"
- 提交前不宣称完成；改动一律引述原文
