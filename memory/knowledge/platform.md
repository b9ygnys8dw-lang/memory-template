# 平台与时间源

> 触发：多端能力差异、MCP、技能/规则生效、取时间、仓库分支、云端环境限制。

## 各端能力

| 入口 | 终端 | 文件系统 | 提交位置 |
|---|---|---|---|
| 网页端 | 无 | 无 | 可能落 `trae/agent-*` |
| 移动端 | 无 | 无 | `trae/agent-*`（committer = trae-solo-agent） |
| 远程沙箱 | 有 | 有（不持久） | main / 任意分支 |

- 云端运行环境是官方 all-in-one 镜像，**会话期间临时存在，不支持自定义镜像**
  `触发: 换镜像、装系统依赖、环境定制`
- 自定义环境仅 Code 模式可用；网页版所有任务都在云端跑
- 网络白名单制，默认放行 npm、pypi、maven、goproxy、github
- 移动端连接桌面端仅限 Code 模式，可访问当前打开的项目，授权 180 天
- 云端任务三端同步；本地任务只在桌面端与移动端之间同步
- 网页端不计入 3 台设备限制

## MCP 与技能

- MCP 与规则在站点侧配置，账号级，可跨会话
- 工具集在会话启动时确定，**不热加载**
  `触发: MCP 配了却调不到、技能没生效`
- 判断是否可用看面板能否列出工具，不看"安装成功"
- 技能按需加载，规则全量注入；要每次生效的内容放规则
- 项目技能在 `.trae/skills/`，全局技能在 `~/.trae-cn/skills`
- 支持上传单个 `SKILL.md` 或 `.zip`；文件必须恰好叫 `SKILL.md`
- 长 description 会稀释命中率，触发条件放正文
- 图谱数据文件：`/workspace/kg-memory.json`；摘要库数据文件：`/workspace/memory.json`
  （必须与 MCP 配置里的 `MEMORY_FILE_PATH` 一致，否则 grep 查的是另一个文件）

## 取时间

1. `bash date -u +%F`（首选）
2. commit 时间戳：任何写入的提交响应带 `author.date`，即服务器当前 UTC；无写入则做一次探针提交读回
3. 用户给的日期
4. 都没有 → 标"无时钟"，跳过需要日期的事，不推算

校验（仅对第 2 条）：与最后一条 commit 相差 ≤ 2 天，否则丢弃改用下一条。

## 分支

- main 是唯一真相源；写入必须落在 main
- 非 main 分支不算写入：先合并，合不了就告诉用户
