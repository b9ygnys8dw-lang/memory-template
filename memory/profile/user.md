> 维护：模型按规则主动写，不需要逐条批准；同类不重复，旧值标作废不删。
> 条目分两类，必须分开写：
> - **事实**：我目睹的行为，带依据 ——「交付一律改名（依据：三次拿到旧版）」
> - **推断**：我对你这个人的解读，标「（推断）」 ——「对系统优雅的兴趣高于立刻能用（推断）」
> 你说"这条不对" → 直接改或标作废，不辩论、不要求证据。
